## 남은 한계·미확인

- HTTP 읽기 timeout은 전체 wall-clock 마감과 같지 않다. 요청 한도는 남은 시간으로 줄이지만, 느린 응답의 읽기 도중 경과 시간은 막지 못한다. 단계 hard stop 6분이 최종 안전장치다.
- 원문 partial 품질은 단계 상태(degraded)와 일간 품질에 반영된다. 카드에는 기업별 partial 표시가 아직 없다.
- 자동 주체·의미 검증은 구조 검사다. "자동 정리·미검토" 표시는 유지한다. 자회사 판정은 인용에 발행사 이름·"the company"·"we" 등이 있는지로 한다.
- 머리글 없는 표 행 수치는 보수적으로 거부한다. 표 머리글과 열을 연결하는 파서는 아직 없다.
- 운영 미확인: v3 초안의 실제 통과율, 원격 예약→발송→영수증 실제 경로, 사용자 /track, 월요일 주간 단계(9/28).
- 로컬 실모델 반복 검증은 하지 않았다. 운영과 같은 API 키의 한도를 쓰기 때문이다.
