# 로직 종합 재점검 및 운영 검증

이전 35개 테스트 결과는 로컬 구현 검증이었다. 원격 운영은 개선 전 코드로 9월 6·7일에도 실행되고 있었으며 새 코드 배포는 누락돼 있었다. 이번 점검은 데이터 통합, 실제 API, 전송, 운영 실행을 포함한다.

## 재점검 범위와 결론

| 범위 | 결론 |
| --- | --- |
| 수집 범위·오탐 | 실제 SEC 60건·RSS 2건 수집 성공. 일반 prepayment 검색을 customer prepayment/deposit으로 좁혀 금융 문서의 검색 슬롯 점유 감소 |
| 원문·모델 검증 | Gemini 실제 5건 응답, 구체적 신호 없는 자료 5건 기각. 오류를 신호로 바꾸지 않음 |
| 기업·가설·원장 연결 | 운영 872개 신호 보존, CRDO 근거 ID를 SIG-0873/0874로 재배정하고 참조 검증 |
| 비교 로직 | 일별 집계 이전에 시계열 정의 혼합을 검사하도록 수정. 동일 날짜 다른 공급자 관측이 감춰지는 오류 차단 |
| 상태 전환 | 종료·제외 가설에 새 근거를 잘못 연결하지 않도록 수정. 중기 승격은 동일 FY 실제 시계열 필요 |
| 반증·복기 | 소급 마진 비교는 재점검이며 사전 예측 성과가 아님. 평가 표본의 적중률은 여전히 미측정 |
| 전송·장애 격리 | Telegram 실제 보고서 전송 성공. 동일 보고서 재전송 방지 및 전송 결과 상태 추가. Reddit 실패와 검토 보고 단계를 분리 |
| EPS 접근 | 실제 재조회 HTTP 402. 컨센서스 0건이며 사업 실적으로 대체하지 않음 |

37개 회귀 테스트가 통과했다. 이는 로직의 알려진 결함과 운영 연결을 점검한 결과이며 투자 성과나 모든 문서에 대한 의미 정확도를 보증하지 않는다.

## 남은 설계 한계

- 수집은 제한된 SEC 검색·RSS 범위와 발췌문에 의존하므로 신호 누락 가능성이 있다.
- 원문 인용의 존재 검증과 내용의 경제적 해석 검증은 다르다. 회사·수혜 경로·독립 출처 대조는 사람 검토가 필요하다.
- 실제 컨센서스 접근이 없어 EPS 리비전·forward PER 판단은 자료 부족 상태다.
- 임계값과 점수의 성과 검증, 30/90/180일 성과 복기는 완료하지 않았다.
- 정확히 일치하는 가격·EPS 날짜가 없는 90일 비교는 추정치 대신 자료 부족을 반환한다.
- 데이터 쓰기는 단일 작성자 전제다. 외부 전송 직후 상태 저장 전에 중단되면 중복 전송 가능성이 남는다.
