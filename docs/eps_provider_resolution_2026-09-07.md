# EPS 접근 제한 해결

FMP의 실제 오류 본문은 현재 구독에서 요청 symbol의 Special Endpoint를 사용할 수 없다는 내용이다. 키를 바꾸는 것만으로 해결되지 않아 추가 결제 없는 Yahoo Finance 공개 분석 페이지로 기본 수집 경로를 변경했다.

공급자는 config/research_policy.json의 eps_provider=yahoo로 선택한다. FMP 코드는 선택 가능한 대안으로 남겨두되 현재 운영에서는 호출하지 않는다. 새로운 가입·키 발급·결제는 필요 없다.

CRDO의 공개 분석 페이지에서 현재·다음 연도의 non-GAAP EPS 컨센서스를 실제 수집했다. 기업 식별자, 통화, 분석가 수, 두 연도, 회계기준, 중복 수치 충돌을 검사한다. HTML 구조나 자료가 맞지 않으면 실패를 표시하고 숫자를 만들어 넣지 않는다. 제공자가 표시한 회계기간 말일은 회사 실제 결산일로 임의 보정하지 않는다.

출처: https://finance.yahoo.com/quote/CRDO/analysis/

Yahoo와 FMP는 다른 시계열이다. 오늘의 두 연도 추정치를 두 번의 상향으로 해석하지 않으며 과거 EPS 상향 이력을 생성하지 않는다. 추적 시계열은 오늘부터 쌓인다. 가격 관측이 없는 상태에서 forward PER 분석까지 해결됐다고 표시하지 않는다.

Import AI 피드는 반복적인 GitHub HTTP 403과 초기 연구 범위 밖의 일반 AI 정책 콘텐츠 때문에 수집 설정에서 제외했다. SEC와 반도체 전문 피드는 유지한다.

공개 페이지 수집은 정식 API의 가용성을 보장하지 않는다. 향후 차단이나 구조 변경은 운영 상태에 드러나며, 그때 실제 이용 가능한 대안을 확인한다.
