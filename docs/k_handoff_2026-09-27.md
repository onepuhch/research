- **확인한 상태**
  - 11434 리스너는 `ollama.exe serve`(PID 22092)였다. 부모는 `ollama app.exe`(22088), 그 부모는 explorer였다.

  - J 시험 때의 숨김 서버는 PC가 꺼지면서 이미 사라진 상태였다. 과거 PID는 쓰지 않았다.
- **활동 여부**: 적재 모델 0(`/api/ps` GET), 연결된 클라이언트 0, 앱 창 없음. 사용자가 쓰는 중이라는 흔적이 없었다.
- **조치**
  - 종료 직전에 조건(명령행, 부모, 활동 0)을 다시 확인하고 두 프로세스만 종료했다.
  - 결과: 포트 리스너 0, ollama 프로세스 0. 종료 당시 모델이 적재돼 있지 않아 GPU에서 해제할 모델 메모리는 없었다(1163MiB 사용, 데스크톱 앱 수준).
- **자동 시작 제외**
  - `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\Ollama.lnk`를 `C:\Users\wls15\.ollama\startup-backup\Ollama.lnk`로 옮겼다(sha256 27C157B9…7B62, 대상 `ollama app.exe`).
  - Ollama 자동 시작은 이것 하나였다. 레지스트리 Run 키나 예약 작업에는 없었다. 다른 시작 항목, GitHub 타이머, 전원 설정은 건드리지 않았다.
